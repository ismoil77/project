# Структура гардероба (`wardrobe.json`, версия 3)

Машиночитаемая схема: [`wardrobe.schema.json`](wardrobe.schema.json). Как AI собирает образ: [`AI_GUIDE.md`](AI_GUIDE.md).

Один файл — источник правды для сайта, утренних уведомлений и Claude.

## Вещь (`items[]`)

| Поле | Пример | Откуда берётся | Зачем |
|---|---|---|---|
| `id` | `top-002` | авто | ссылка на вещь (форма, чат) |
| `status` | `active` / `archived` | авто, кнопка «В архив» | архивные не попадают в образы |
| `archived` | `{date, reason, comment}` | форма архива | почему перестал носить |
| `name`, `brand`, `category`, `type` | «Свитер», LC Waikiki, Верх, свитер | ты | — |
| `type` | футболка, джинсы, кроссовки, туфли | ты | срок службы, сочетания |
| `color` | `{name, hex, family, tone, secondary[]}` | **авто по фото** или ты | основной цвет и доли других; `family`: нейтральный / землистый / тёплый / холодный; `tone`: светлый / средний / тёмный |
| `pattern` | однотонный, полоска, клетка, принт / надпись | ты | один узор на образ |
| `formality` | 1 спорт · 2 повседневный · 3 смарт-кэжуал · 4 деловой · 5 строгий | ты | стиль образа, сочетание обуви с брюками |
| `material`, `size` | 100% хлопок, 52 | бирка | уход, теплота, посадка |
| `insole_cm` | 26,5 | ты (обувь) | точный размер обуви |
| `season` | `["межсезонье"]` | «Сезон и плотность» | лето / межсезонье / зима |
| `thickness` | тонкая / средняя / плотная | «Сезон и плотность» | — |
| `warmth` | 1–5 | «Сезон и плотность» | слои при подборе |
| `temp` | `[13, 22]` | по `warmth`, можно уточнить | при какой ощущаемой °C комфортно |
| `layer` | база / средний / верхний | авто по категории | порядок слоёв |
| `sheer` | «просвечивает на свет — видно силуэт» | ты (фото на просвет) | тонкий светлый верх на работу — с майкой под ним |
| `windproof`, `waterproof` | true / false / «морось» | ты | ветер, дождь |
| `occasions` | `["Работа","Повседневно"]` | ты | где можно носить; пусто — везде |
| `condition` | отличное / хорошее / есть дефекты / только дом/спорт | ты | — |
| `flaws`, `flaw_notes` | `["пятно"]`, «на левом рукаве» | ты | не надевать на выход, предупреждать |
| `added` | `2026-11-08` | **авто**, день загрузки | возраст вещи, если дата покупки неизвестна |
| `purchased` | `{date:"2024-10", approx:true, text:"осень 2024"}` | ты, примерно | возраст и «пора заменить» |
| `price`, `link` | 2500 ₽, ссылка WB | ты | — |
| `care`, `notes` | 30°, наизнанку | бирка / ты | — |
| `photos` | `wardrobe/photos/top-002-1.webp` | форма | первое — обложка |
| `history` | `[{date, event, note}]` | **авто** | журнал: добавлена, обновлена, в архив |

### Дата покупки — как писать
Подойдёт любое: `осень 2024`, `март 2025`, `09.2025`, `2023`, `год назад`, `1,5 года назад`, `полгода назад`, `недавно`, `летом`.
Если точно не знаешь — пиши примерно, отметка `approx` это учитывает. «Не помню» — не заполняется, тогда возраст считается от `added`.

## Обувь
Та же структура, `category: "Обувь"`, плюс `type` (кроссовки, кеды, туфли, лоферы, ботинки, сапоги, сандалии), `insole_cm`, `waterproof` (для дождя), `formality`.
При подборе обувь не должна быть формальнее брюк больше чем на 1 (туфли со спортивками — нет), в дождь предпочитается `waterproof: true`.

## Как определяется цвет
По фото без фона: 5 главных оттенков (median-cut) → ближайшие названия из палитры (`scripts/colors.py`) по расстоянию в CIELAB. Самый большой — `color.name`, остальные с долей ≥ 12 % — `color.secondary`.
Если владелец написал цвет сам — его название главнее, автоматические оттенки сохраняются как дополнительные.

## Срок службы (`lifespan_years`)
Ориентир, через сколько лет вещь обычно пора обновить. Сначала ищется по `type`, потом по `category`.
Средний срок жизни одежды по данным WRAP (Великобритания) — около 3,3 года; куртки и пальто ~4,6, свитера ~3,5.
Это только подсказка: сайт отмечает вещь «⏳ пора обновить», если возраст ≥ срока **или** есть дефекты вроде «выцвел», «дырка», «растянулась».

## Как добавлять
- **Через сайт** — кнопка «+» → форма на GitHub. Обязательно только фото.
- **Через Claude** — присылай фото и пиши нюансы обычным текстом («купил примерно осенью 2024, на локте катышки, на работу не ношу»). Claude сам разложит по полям.
