# Гардероб

Каталог моих вещей с фото. Страница сама показывает прогноз погоды в Душанбе на 4 дня и подсказывает, что надеть утром из того, что уже есть.

- Сайт: `index.html`, бесплатно хостится на GitHub Pages
- Данные: `wardrobe/wardrobe.json`, их читает и обновляет Claude
- Фото: `wardrobe/photos/`

## Как добавить вещь
Пришли Claude фото вещи целиком и фото бирки с составом. Он сам добавит запись в `wardrobe.json` и положит фото.

## Поля вещи
Полное описание структуры: [`wardrobe/SCHEMA.md`](wardrobe/SCHEMA.md). Там есть дата добавления, примерная дата покупки, сезон и плотность, состояние и дефекты, где носить, архив и срок службы.

## Добавление вещей с телефона
Кнопка «+» на сайте открывает форму «Добавить вещь» на GitHub. Прикрепляешь фото, сколько нужно, и заполняешь поля.
Дальше GitHub Action (`.github/workflows/add-item.yml`) сам:
1. скачивает фото;
2. удаляет фон через [rembg](https://github.com/danielgatis/rembg) (модель `isnet-general-use`, бесплатно, работает прямо на GitHub);
3. сохраняет WebP в `wardrobe/photos/` и добавляет вещь в `wardrobe.json`;
4. отвечает в issue и закрывает его.

Добавлять вещи может только владелец репозитория. Удалить фон у одного фото локально: `python scripts/add_item.py cutout in.jpg out.webp`.
